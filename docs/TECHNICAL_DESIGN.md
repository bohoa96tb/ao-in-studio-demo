# TECHNICAL_DESIGN
Studio module uses one local state snapshot, faces front/back, layers with image/text geometry. Draft snapshot including uploaded raster data lives in IndexedDB, history memory capped at 30. No localStorage images or upload API. canvas front/back passed into CanvasTexture, original procedural extrusion and side materials; one WebGL canvas on demand, render only on events. Separate design from prepared motion footage.

Cart module owns independent immutable design snapshots and preview PNGs in IndexedDB (cart key). Editing passes a cloned snapshot to Studio; only explicit edit row identity replaces existing line. unitPrice charges 199000 + 30000 per nonempty face. New adds always create unique row UUIDs. No payment data or server request. Cart and draft saves report completion only after transaction completes.

Studio read-only snapshot()/preview(face,plain) feeds styling and heat press modules; studio-change marks previews dirty. Consumers render from same current draft, not independently editable copies. Preview rasterization occurs when effect visible or requested. Fitting/cart and press/cart invoke existing Studio add action with edit-row identity preserved. Timers invalidated on Studio changes/tab hidden/offscreen.

Catalog reads data/products.json; catalog-filter.js provides pure accent normalization/filtering/preset factory. Studio.mockup renders explicit supplied design without mutating working draft. Studio.newDesign keeps prior working snapshot in undo history. Base price constrained to 199000/219000/239000 by unitPrice; printed-side surcharge shared across catalog/Studio/cart. All catalog templates unisex, so gender filters include unisex records.
